# Number Guessing Game 🎯

This is a simple console-based **Number Guessing Game**, implemented in both **Python** and **Java**. The program generates a random number between 1 and 100, and the user has to guess it in as few tries as possible.

## 📜 How It Works

- The program picks a random number between 1 and 100.
- The user is prompted to guess the number.
- After each guess, the program gives feedback:
  - "Too low!"
  - "Too high!"
  - "Congratulations!" when guessed correctly.
- Input is validated to ensure it's a number within the correct range.
